# Datenschutzerklärung GymTracker

Dieses Repository hat genau einen Zweck: die Datenschutzerklärung der Android-App
**GymTracker** unter einer öffentlich erreichbaren Adresse bereitzustellen. Google Play
verlangt dafür eine URL, auch bei einer App, die nichts überträgt.

Veröffentlicht über GitHub Pages:
**https://duke0815.github.io/gymtracker-datenschutz/**

Der Quellcode der App liegt in einem eigenen, privaten Repository. Aus einem privaten
Repository liefert GitHub Pages nur mit kostenpflichtigem Plan aus — deshalb diese
Trennung, und deshalb steht hier nichts als die eine Seite.

## Ändern

`index.html` bearbeiten, committen, pushen. Die Seite ist eine einzelne Datei ohne
Abhängigkeiten; nach dem Push dauert die Aktualisierung ein bis zwei Minuten.

Das Datum steht an zwei Stellen: im Kopf der Seite („Stand …“) und im Abschnitt
„Änderungen“ als Hinweis. Bei inhaltlichen Änderungen beides nachziehen.

Eine inhaltsgleiche Fassung liegt im App-Repository unter `store/datenschutz.md`. Werden
Angaben geändert, gehört sie mitgezogen, damit die beiden nicht auseinanderlaufen.
